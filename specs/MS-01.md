## Reconciliation duties (G1, from MS-00 §8)

MS-01 owns startup reconciliation over the MS-00 ledger, executed inside the
MS-08 writer before proposals are accepted: verify hash chain, acquire write
lease, rebuild projections from `events` alone (disagreement ⇒ abort), classify
interrupted attempts to terminal `FAILED`/`AUDIT_FAILED` (never manufactured
success), stale task leases ⇒ `blocked`, in-flight jobs ⇒ `interrupted`, append
`control.reconciled` checkpoint.

## Provider resolver contract (canonical target, from PR #284)

Verified against `main@3cff6bcd`; executable vectors:
`tests/modular/test_resolver_adversarial.py` (indexed in
`specs/source-archive/`).

1. **Single resolution entry point.** Every provider reference resolves through
   one resolver returning a fully-bound, dispatchable target or a structured
   refusal.
2. **Parse = dispatchable.** A name admitted at parse time MUST be
   dispatchable; undispatchable vocabulary members are refused at parse.
3. **Kind↔host pinning.** First-party kinds (openai, anthropic, google, azure,
   bedrock) bind to canonical hosts; `base_url` override honored only for
   `openai_compatible` (loopback/local) and explicitly self-hosted kinds.
4. **Credential handles are total.** A handle is bound (saved),
   environment-derived (explicitly reported), or absent. `clear` means absent
   from every source; env inheritance must be explicit, never silent fallback.
5. **Loopback policy is exact.** Local routes accept only the literal loopback
   set `{localhost, 127.0.0.1, ::1}`; encoded, partial, credentialed, or
   decorated variants refused.
6. **Bounded, distinct failover; no cross-model stream concatenation.** ≤5
   distinct candidates; a stream that has emitted a prefix never switches
   models mid-stream.
7. **Stable identity.** Identical inputs hash identically; volatile fields
   (timestamps, request ids, hold ids) never enter identity hashes; canonical
   JSON uses sorted keys and rejects non-finite numbers.
8. **No implicit aliasing.** Model/provider names match exactly; any future
   alias table is part of the resolver contract and versioned.

| # | Gap | Migration step |
|---|---|---|
| M-1 | Parse admits undispatchable `router` name (F-2) | Split vocabulary into dispatchable providers vs internal roles; refuse at parse |
