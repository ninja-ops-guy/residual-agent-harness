# Release Claim Language

Preferred precise language:

- "published WebVM desktop/narrow Chromium acceptance passed"
- "published provider helper loaded the real Puter SDK; authentication and inference were not run"
- "real provider inference passed on retained user-account evidence"
- "physical iOS/WebKit acceptance passed/failed/not run"

Avoid ambiguous phrases such as "mobile passed", "provider passed", or "demo fully qualified" unless every implied layer is explicitly enumerated and evidenced.
