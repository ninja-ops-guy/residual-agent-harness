# Agent Do-Not-Assume List

Do not assume:

- green fixture tests mean a third-party SDK can load;
- a provider tab opening means its SDK initialized;
- SDK initialization means authentication works;
- authentication means inference works;
- inference means RESIDUAL accepted a candidate;
- a generated artifact is what GitHub Pages currently serves;
- a successful later deployment erases a first failed deployment;
- narrow Chromium represents Safari/WebKit;
- a service worker only affects the page that registered it;
- fixing `/provider/` permits weakening `/demo/` isolation.

Prove the exact layer or report it as NOT_RUN/UNKNOWN.
