# Agent Stop Conditions

An agent must stop automatic merge/release progression and surface the evidence when:

- exact head or deployed identity cannot be established;
- required published-origin evidence is unavailable;
- real SDK loading fails;
- `/demo/` and `/provider/` isolation states violate their contracts;
- physical-device evidence contradicts simulated/narrow evidence;
- a first production attempt fails;
- a proposed fix would broaden privileges or weaken WebVM/verifier/provider protocol boundaries merely to obtain green.

Continue only after a scoped fix produces fresh evidence on a new revision.
