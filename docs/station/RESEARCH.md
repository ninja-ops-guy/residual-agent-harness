# Research position

The hypothesis is that revision-aware selective sharing of verified progress reduces repeated reasoning per successfully integrated specification. Deterministic coordination, scoped source, local inference, residual escalation and review receipts are the mechanisms to evaluate. A combination of known techniques is not automatically a novel contribution.

Closest prior art:

- [DeLM](https://arxiv.org/html/2606.10662v1) already uses task queues, shared verified progress, compact gists and selective expansion. Shared verified state alone is not novel.
- [AgentPrune](https://arxiv.org/abs/2410.02506) evaluates token reduction through communication pruning.
- [SupervisorAgent](https://arxiv.org/abs/2510.26585) reduces unnecessary supervision through runtime filtering.
- [LDD Kit](https://github.com/ninja-ops-guy/LDD-Kit) supplies this integration's log-driven event-contract foundation.

The narrower candidate contribution is a protocol joining local execution, revision-bound acceptance, selective cloud reports and residual repair. Establishing novelty requires broader prior-art comparison and matched-quality evaluation.

Compare a strong single agent, naive broadcast group chat, isolated orchestrator workers, selectively shared state, and this station. Hold tasks, models, tools, budgets and acceptance criteria comparable. Separately ablate cloud routing, shared reports, review gating and local execution.

Measure provider-reported local/cloud tokens, calls without usage, separately reported worker usage, repeated context, request bytes, total cost per successful integration, retries, regressions, latency and local hardware consumption. Bytes are not tokens; pricing cache discounts and token-count reductions are different measurements.

The training mission uses scripted proposals and real checks. It proves workflow plumbing, not model quality, savings, or cloud necessity. The original RESIDUAL synthetic benchmark remains a request-byte experiment. Neither is a live-model efficiency result.
