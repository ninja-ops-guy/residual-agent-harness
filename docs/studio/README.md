# Residual Studio

Residual Studio is the proposed v1.0+ platform layer for self-hosted, evidence-driven multi-swarm engineering.

Start here:

- [`PLATFORM_VISION.md`](PLATFORM_VISION.md) — product thesis, architecture, operating model, and research questions.
- [`STUDIO_SPECS.md`](STUDIO_SPECS.md) — normative RFC-2119 requirements for the five-layer architecture, requirement compiler, swarm runtime, evidence bus, parallel metrics, cluster, IDE, and deterministic integration.

The existing Residual Station remains the verification and safety kernel. Studio extends the current harness into a platform without weakening its receipt, policy, verification, and HITL boundaries.
