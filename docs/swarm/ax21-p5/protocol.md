## Logging and analysis

Use the blank CSV for each session. Record checkpoint reveal and submit/timeout as clock boundaries, purpose-level interventions as events, and continuous non-overlapping operator intervals as active or idle. Count one query, broadcast (record recipients), owner status ping, external lookup, manual ledger edit, correction, retry or escalation per intentional action, not per click. Record required owner requests separately. Link derived events with parent_event_id; a broadcast counts once. Mark manual comparison intervals with all report and evidence IDs. Reconciliation effort is the union of comparison time and number of distinct report IDs actually compared. Also report deduplicated logical reports (R14 duplicates R13). Record automated requests/model calls, actual latency, retries and helper labor separately. Use one synchronized monotonic clock per session with UTC anchors; log setup, curation, packaging and scoring by actor outside trial time. Concurrent actions never double-count the same human second.

For each checkpoint publish active seconds, wall seconds (including idle), intervention counts by type, distinct external sources and reports reconciled, reconciliation seconds, model calls, roster coverage (/11), fresh/stale current assertions, evidence-backed claims / material claims, correct fields / 55, and failures. Preserve raw values and B minus A per pair, total operator and total all-role time, including treatment-only setup. Named waits are task dependencies. Record the explicit decision text for the owner gate. An unverified claim must be reported as such, with its dependency blocked. Credit semantically equivalent wording. Score each key cell separately; require source class, ID and time for traceability. For a stale field cite the last observation and expiry. For receipt absence retain the cutoff-bounded verifier ledger/query demonstrating absence. Cross-check release of the positive dependency against both the receipt and the D event. Missing seats or unsupported unknowns cannot earn correctness credit.

A qualifying pilot requires four scoreable complete sessions with 11/11 coverage at both cutoffs; both pairs must achieve B active seconds summed over checkpoints <= 0.75 × A (A > 0), strictly fewer cold individual queries and strictly fewer ongoing manually reconciled reports. Per pair and checkpoint B field correctness and traceability proportions must equal or exceed A. Require both arms to correctly handle both completion controls, expiry and the genuine owner gate. Any false verification, improper dependency clearance, or invented approval fails. Report ties, unchanged external-ledger dependency, extra helper time, and status pings explicitly. If human costs move elsewhere, describe the transfer. Four sessions yield descriptive paired evidence, no population inference.
