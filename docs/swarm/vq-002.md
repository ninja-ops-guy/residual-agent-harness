# SPEC-SWARM-VQ-002 — Verifier Quality Framework

Status: implemented
Branch: `swarm/vq-002-verifier-quality`
Swarm: B

## Purpose

Measure and gate the quality of the acceptance boundary instead of assuming
verifier correctness. Implemented under `residual/vq/` on top of the existing
`residual/verifier.py` / `residual/receipts.py` machinery (no changes to those
files; the VQ package composes with them).

## Evidence (Gates B and C)

`evidence/vq/vq-002-benchmark.json` — machine-readable summary artifact; raw
labeled outcomes are stored as hash-listed JSONL chunks alongside it
(`outcomes-{degraded,adequate}.part{0,1,2}.jsonl`, SHA-256 per chunk recorded in
the summary's `raw_outcome_files` block). The artifact set contains:

- exact commit/branch identity of the code under test, runtime versions;
- gate configuration, verifier identity (all VQ-R2 hashes), fixture hash;
- **raw labeled outcomes** (130 cases: 100 correct, 30 known-defect);
- two benchmark runs: a degraded verifier (precision estimate 0.909, Wilson
  lower 0.841 < 0.95 ⇒ **fail-closed HITL escalation**) and an adequate
  verifier (accepted);
- reproduction block: profile and gate recomputed solely from the retained
  raw labeled outcomes match the report (`recomputed_profile_matches: true`).

Evidence artifact SHA-256 (`evidence_hash` field, current value
`96bcfca65370fadd611381f48072e4a50637686a2b0a2f8664697a95437fa4d9`): recorded
inside the artifact; it covers the summary body (excluding the `evidence_hash`
field) serialized with `json.dumps(..., separators=(",",":"), sort_keys=True)`.

Note: report hashes (`report_hash`) exclude wall-clock data, so the
profile/gate reproduction is fully deterministic; only the git identity block
depends on the checkout.

## Design notes

- **Fail-closed semantics (VQ-R4/R9):** the gate evaluates the *lower Wilson
  bound* of precision against the 0.95 threshold, and treats UNKNOWN
  (insufficient samples) as an escalation, not an acceptance. There is no code
  path from `accept_or_escalate` to silent acceptance when precision is
  degraded or unmeasured.
- **Ensemble determinism (VQ-R5):** members are sorted by name at
  construction; aggregation is a pure function of member verdicts and the
  declared policy; ties resolve via an explicit `tie_break` (default
  fail-closed `reject`).
- **Frozen fixture scope (VQ-R6):** Swarm A (EVAL-001) owns the full
  FrozenWorkload schema. `residual/vq/frozen.py` defines only the
  labeled-defect slice needed for verifier benchmarking; fixtures are hash-bound
  and tamper-evident (`fixture_hash` mismatch ⇒ load failure).
- **VQ-R3 enforcement is structural:** `LabeledOutcome` refuses construction
  with `WORKER_SELF_REPORT`, and `OutcomeStore.add` re-checks provenance so
  deserialized/tampered objects cannot bypass the rule.
