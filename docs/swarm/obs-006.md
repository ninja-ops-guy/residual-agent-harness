# SPEC-SWARM-OBS-006 — Observability + Reliability Telemetry

Swarm F implementation. Raw observations are the authoritative evidence;
metric registries and the Prometheus export are derived, non-authoritative
views (OBS-R2). Reliability reports recompute every paper-facing metric
from raw observations alone (OBS-R4).

## Layout

- `residual/telemetry/schema.py` — observation schema version, kinds,
  phases, required fields, validation, canonical hashing (`EvidenceError`).
- `residual/telemetry/labels.py` — bounded-cardinality label sanitizer
  (allowlist + overflow bucket; forbidden high-cardinality keys).
- `residual/telemetry/metric_families.py` — OBS-R1 metric families built on
  `residual.observability.metrics`; `TelemetryCollector` ingests validated
  raw observations and retains them as authoritative evidence.
- `residual/telemetry/exporter.py` — Prometheus text exposition
  (`AUTHORITATIVE = False`).
- `residual/telemetry/report.py` — reliability report builder: recomputes
  all aggregates from observations, rejects corrupt evidence, attaches
  evidence completeness to every aggregate, emits schema version + hash.
- `residual/telemetry/fixtures.py` — deterministic frozen fixture
  (`obs006-fixture-v1`) covering every observation kind and phase.
- `residual/telemetry/evidence.py` — Gate B evidence artifact generator
  (`python3 -m residual.telemetry.evidence`).
- `tests/swarm/test_obs006.py` — 41 deterministic fixture tests.
- `evidence/obs/obs006-evidence.json` — machine-readable evidence artifact
  (commit/tree identity, runtime, raw observations, observation hash,
  Prometheus export, exported report, reproduction check).

## Gates

- **Gate A**: every requirement maps to ≥1 test;
  `python3 -m pytest tests/swarm/ -q` → 41 passed.
- **Gate B**: `evidence/obs/obs006-evidence.json` records commit/tree/branch
  identity, Python runtime, the raw fixture observations, observation hash,
  the Prometheus export, and the exported report.
- **Gate C / acceptance**: `test_identical_inputs_produce_identical_report_hash_twice`
  and `test_fresh_fixture_rebuilds_paper_metrics_from_observations_alone`
  prove identical inputs yield identical report hashes and that all
  paper-facing metrics are rebuilt from observations alone. The evidence
  artifact also performs the rebuild twice and records
  `reproduction.identical_hash = true`.

## Invariants

- Failures remain in denominators; missing evidence is counted, not dropped.
- Label values outside the explicit allowlist fold into `__other__`;
  forbidden keys (task/content/run/session/trace ids, prompts, payloads)
  raise `LabelCardinalityError`.
- Report hash is SHA-256 over canonical (sorted-key) JSON of the report
  body; observation hashing is order-independent.
