- [x] License scope is machine/human-reviewable through the Open Source Manifest.
- [x] Enterprise/commercial paths are explicitly excluded from the grant.
- [x] Contribution/provenance policy exists.
- [x] Security reporting policy exists.
- [x] Direct dependency licensing is inventoried.
- [x] Funding disclosure boundary is documented.
- [x] Open-source funding is earmarked to open-source/research work by policy.
- [x] Trademark rights are not granted beyond Apache-2.0 requirements.
- [ ] Independent legal review of employment/invention-assignment terms before material commercialization.
- [ ] Full transitive SBOM before packaged release.
