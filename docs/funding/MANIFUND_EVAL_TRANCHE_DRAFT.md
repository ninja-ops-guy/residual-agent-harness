# RESIDUAL — focused agent-evals tranche

**Status:** DRAFT / not an accepted grant  
**Target funder:** Manifund regrantor fit (Marius Hobbhahn / evals)  
**Duration:** 8–10 weeks  
**Request:** **$7,500**

## Question

Does host-controlled acceptance using candidate-bound evidence, explicit authorization, independent verification, and retained receipts improve verified software-agent outcomes relative to simpler agent workflows under matched tasks and inference budgets?

## Scope

This tranche funds a bounded evaluation study, not general RESIDUAL development.

### Conditions

1. direct/minimal agent workflow baseline;
2. evidence retention without independent acceptance;
3. verification without explicit authority separation;
4. selected control ablations;
5. full evidence-bound acceptance.

### Measurements

- independently correct task completion;
- accepted actions versus generated outputs;
- unauthorized accepted transitions;
- verifier rejection/abstention;
- recovery success;
- operator interventions;
- inference cost;
- verification cost and coverage.

## Deliverables

- frozen/preregistered task and ablation manifest;
- deterministic analysis code;
- retained revision-bound evidence;
- at least one replication of material failures;
- public evaluation summary including negative/null findings;
- sanitized reproducibility package suitable for independent challenge.

No customer acquisition, proprietary enterprise features, hosted-product work, founder distributions, or unrelated development are funded.

## Stop / success criteria

A successful tranche does **not** require the hypothesis to be true.

The tranche is complete when:
- protocol and task set are frozen;
- all planned conditions have either run or have a documented preregistered stop reason;
- primary metrics and uncertainty are reported;
- material failures are retained;
- funded public artifacts are released under the agreed research/open-source terms.

## IP / funding boundary

RESIDUAL predates this tranche. Funding covers the defined evaluation work, public research artifacts, compute/API consumption and directly associated research services.

Pre-existing and independently funded commercial/enterprise implementation, trademarks, customer-facing work and hosted-service development remain outside the funded scope.

No expense funded by another grant will be charged again here.
