Access to this website

We aim to make the public website usable with keyboards, screen readers, zoom, and reduced-motion preferences. These legal pages use semantic headings, visible link and focus styles, responsive text, and a skip-to-content link. These are implementation choices, not a certification that every RESIDUAL interface meets a particular accessibility standard.

Known limits and alternatives

The experimental browser VM and terminal are complex interactive interfaces and have not been demonstrated to be fully accessible across assistive technologies and browsers. Use the text-oriented walkthrough and repository documentation as alternative ways to learn about the project. An alternative page does not replace the obligation to fix an inaccessible service where the law requires it.

Contact and assistance

Security reports

Follow the security policy. Use GitHub's private vulnerability-reporting route when available. Never put exploit details, personal information, keys, or tokens into a public issue; contact the operator privately when a secure channel is needed.
