INTERACTIVE / DETERMINISTIC WALKTHROUGH

Watch reliability emerge around an unreliable worker.

This is a scripted, backend-free demonstration of the RESIDUAL control model. The worker is allowed to be wrong. The harness is responsible for containing, observing, verifying, repairing, and integrating only supported work.

Important: this page does not pretend to run a live model. Every transition is deterministic so visitors can inspect the architecture without confusing a marketing animation for runtime evidence.
